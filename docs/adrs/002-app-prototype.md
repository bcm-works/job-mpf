# 002 - App is prototype

## Status

`Approved on 7 Sep 2026`

## Context

In order to lower implementation time and code complexity, this submission will be treated like a prototype.

This focus will delay implementation of various more complex and time consuming features to later on in the project, so that a MVP can be used to demostrate the core project goals.

## Decisions

1. Single user, no user management features or permission levels
2. Authentication for the [Movie DB](https://www.themoviedb.org/) API is via backend environment variables 
3. The frontend app design is bare-bones to reflect the unfinished nature of the intial state of the app

## Consequences

- Engineering time for the skipped features will require future scoping based on agreed requirements
- The MVP will not meet every goal from the [project plan](../external/technical-test-exercise.pdf)
